## Web skill scope in Claude Code

- Use `nextjs-principles` and `react-principles` for framework and component work. Check server and client boundaries before changing data fetching or state.
- Use `forms-validation` for forms. Verify labels, keyboard access, and inline errors.
- Use `design-engineering` and `ui-ux-principles` for UI changes. Reuse the PMS design system.
- Follow the imported rules when a named skill is unavailable.
- For UI changes, report the viewport, theme, and interaction checks you actually run.
